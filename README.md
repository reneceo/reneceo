**[claude-dictation-hotkey](https://github.com/reneceo/claude-dictation-hotkey)**
— a push-to-talk keyboard shortcut for the microphone button in the Claude
desktop app on macOS. Six open issues concluded it couldn't be done; the button
is invisible to the accessibility API until you set `AXManualAccessibility` on
the Electron process, and then it's just an `hs.axuielement` press away.
